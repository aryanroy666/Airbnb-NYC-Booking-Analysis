# Dataset

The raw CSV is not stored in this repository.

1. Download **New York City Airbnb Open Data** from Kaggle:
   https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data
2. Extract `AB_NYC_2019.csv` and place it in this folder, so the path is `data/AB_NYC_2019.csv`.
3. Run the notebook from the repository root.

Expected shape: 48,895 rows x 16 columns.
